# Troubleshooting LocalAgent

- **Installer refuses a retained stage/rollback:** close LocalAgent, preserve both folders, and follow [recovery](RELEASE.md#recovery-and-rollback). The installer deliberately avoids overwriting a previous recovery copy.
- **Extraction fails:** check free disk space, standard-user write access and Windows built-in tar.exe. The previous installation is retained. Do not delete your user-data folder.
- **Startup stops:** use the explicit Retry/Restart action once after checking the installation and ports. Runtime lifecycle metadata identifies credentials, gateway, configuration or engine stage. A pre-runtime shell failure records bounded `desktop-boot-error.json` in user data. There is no automatic prompt replay.
- **Runtime crashes:** the UI preserves the draft; restart the local runtime and review the interrupted task before continuing. Old Gemini tool histories can fail closed after signature metadata expires/restarts. This is not a promise of resumed inference or universal failover.
- **Credential cannot unlock:** use the Windows account that saved it. Remove/re-enter the key in Connections if needed. Never paste keys, credential files or full runtime databases into an issue.
- **Provider is configured but unavailable:** check its free-tier attestation, current catalog, local availability and routing reason. Quota headers are observations. Unsupported routes remain excluded; a paid model is never an automatic recovery option.
- **Preview is blank:** supported projects use static index.html and relative HTML/CSS/JavaScript/assets. Inspect console/build diagnostics; external APIs/assets, service workers and arbitrary framework servers are blocked/deferred. Run Inspect explicitly for a new screenshot. Web development mode may require a browser reload after restarting its runtime.
- **Project tests need missing tools:** desktop bundles its own coding/runtime/browser infrastructure, not every language/package manager. Approve only commands you understand. Agent command permissions are not an OS sandbox.

Logs stay local. LocalAgent routing and gateway logs retain bounded current/previous generations; upstream databases may retain their own history. Console output is untrusted and should be inspected before sharing. A support report should include LocalAgent/Windows version, installer hash, sanitized error code/stage, reproduction steps and expected behavior. Do not attach provider keys, signatures, raw conversations, project secrets or full browser profiles. A public support/security contact has not been chosen.
